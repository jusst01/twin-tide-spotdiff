Twin Tide is an original spot-the-difference game drawn procedurally on canvas: three harbour scenes (Dawn Harbour, Noon Market Pier, Dusk Lighthouse), each with 7 differences between the two side-by-side pictures. Click a difference to ring it on both panels; the counter shows how many remain. Arrow keys move the crosshair, Enter marks. Fewest misses, fastest time wins.

Entry for the make.fun bounty: https://make.fun/bounty/best-spot-the-difference-game-20261121-0451

## Play
Open game/index.html in a desktop browser (or serve the repo root with serve.ts). No network requests; all files are static under game/.
